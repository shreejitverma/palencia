## 2. Role charters

### 2.3 CEO / Founder

- **Mission:** Hold the company to its promise — *certified diamonds, handcrafted jewelry, honest prices* — and make the calls that protect long-term trust over short-term gain.
- **Reports to:** Owners / Board `TODO: [governance body, if any]`
- **Key responsibilities:**
  - Set strategy, annual plan, and budget with department leads.
  - Own final decision rights above delegated thresholds (see [Decision-Making](decision-making.md)).
  - Steward culture and values; final escalation for ethics and customer issues.
  - Approve major supplier, capital, and hiring decisions.
- **KPIs:** Revenue & margin vs. plan; **repeat + referral rate** (north-star trust metric); brand reputation `[target]`; employee retention `[target]`.

### 2.4 Head of Merchandising / Buyer

- **Mission:** Curate a collection customers love and secure the certified stones to sell it — profitably and responsibly.
- **Reports to:** CEO
- **Key responsibilities:**
  - Assortment planning, price-point architecture, newness.
  - Source GIA/IGI-certified stones from vetted suppliers; negotiate terms.
  - Own supplier relationships and initiate supplier due diligence with Compliance.
  - Manage buying budget and stone-level margin targets with Finance.
- **KPIs:** Sell-through rate `[target]`; gross margin on merchandise `[target]`; inventory turns `[target]`; % suppliers with current due-diligence on file (target: 100%).

### 2.5 Gemologist

- **Mission:** Guarantee that every stone is exactly what its certificate says — so "certified" is never just a word.
- **Reports to:** Head of Merchandising
- **Key responsibilities:**
  - Verify incoming stones against their GIA/IGI grading reports (identity, 4Cs, measurements).
  - Provide independent valuation input for pricing (kept separate from buying).
  - Re-verify stones on returns/resizes before they re-enter inventory or a refund is issued.
  - Advise Custom Design and Sales on stone selection.
- **KPIs:** Certificate-match verification rate (target: 100% before intake); valuation accuracy vs. market `[target]`; zero misgraded stones shipped.

### 2.6 Master Jeweler / Setter (Head of Production)

- **Mission:** Hand-craft pieces we would be proud to wear ourselves, and never let a deadline lower the bar.
- **Reports to:** CEO
- **Key responsibilities:**
  - Hand-set stones; fabricate, size, and finish pieces.
  - Execute custom commissions from approved designs.
  - Own production scheduling and craftsmanship standards.
  - Feed defects back into supplier/process improvement.
- **KPIs:** First-pass QC yield `[target]`; on-time production `[target]`; rework rate `[target]`; craftsmanship defect escapes (target: 0).

### 2.7 QC Lead

- **Mission:** Be the last, independent gate — no piece leaves Palencia that isn't right.
- **Reports to:** Master Jeweler (independent sign-off authority)
- **Key responsibilities:**
  - Final inspection against spec: stone identity vs. certificate, carat weight, setting security, metal & hallmark, finish.
  - Authority to **hold** any piece; no override for deadlines.
  - Maintain QC records and defect trends.
  - Verify inbound returns before restock/refund with the Gemologist.
- **KPIs:** Defect escape rate (target: 0); QC cycle time `[target]`; % shipments with completed QC record (target: 100%).

### 2.8 Head of Sales & Customer Experience

- **Mission:** Turn a big, emotional decision into a confident, pressure-free one — and keep customers for life.
- **Reports to:** CEO
- **Key responsibilities:**
  - Own the customer journey pre- and post-sale.
  - Custom-design consultation and quoting.
  - Set service standards (no-pressure selling, generous support).
  - Own repeat and referral performance.
- **KPIs:** **Repeat + referral rate** `[target]`; CSAT / review score `[target]`; conversion rate `[target]`; complaint resolution time `[target]`.

### 2.9 Customer Experience Specialist

- **Mission:** Make every customer feel like our only customer, at every touchpoint.
- **Reports to:** Head of Sales & CX
- **Key responsibilities:**
  - Answer pre-sale questions (4Cs, fit, budget, timelines) honestly.
  - Manage order status, resizing, warranty, and returns (RMA authorization).
  - Escalate issues quickly; resolve generously within policy.
  - Capture customer feedback for the business.
- **KPIs:** First-response time `[target]`; CSAT `[target]`; return/warranty handling accuracy `[target]`.

### 2.10 Head of Marketing

- **Mission:** Grow honest demand and tell the Palencia story so well that trust arrives before the customer does.
- **Reports to:** CEO
- **Key responsibilities:**
  - Brand, content, social, email, paid acquisition, and reputation.
  - Website merchandising and conversion (with Operations).
  - Ensure every claim is true and substantiated — no oversold grades.
- **KPIs:** Qualified traffic & leads `[target]`; customer acquisition cost `[target]`; return on ad spend `[target]`; review volume & rating `[target]`.

### 2.11 Operations / Fulfillment Manager

- **Mission:** Move stones and orders accurately, securely, and on time — every single time.
- **Reports to:** CEO
- **Key responsibilities:**
  - Inventory control and high-value stock security.
  - Insured shipping with signature confirmation.
  - Systems, tooling, and logistics vendors.
  - Returns logistics and physical stock reconciliation.
- **KPIs:** On-time ship rate `[target]`; order accuracy `[target]`; inventory shrinkage (target: 0); shipping-loss incidents (target: 0).

### 2.12 Finance & Compliance Officer

- **Mission:** Protect the company's money and its license to operate.
- **Reports to:** CEO
- **Key responsibilities:**
  - Bookkeeping, AP/AR, cash, financial controls, reporting.
  - Pricing governance (honest, defensible pricing).
  - AML/KYC program for a dealer in precious stones/jewels (FinCEN).
  - Responsible-sourcing program: Kimberley Process, supplier due diligence, OECD guidance, RJC alignment.
  - Veto power over transactions failing controls or due diligence.
- **KPIs:** Clean books & on-time close `[target]`; % suppliers with completed due diligence (target: 100%); AML/KYC exceptions resolved `[target]`; audit findings (target: 0 material).

### 2.13 People / HR Lead

- **Mission:** Hire for values, grow people, and keep the team well.
- **Reports to:** CEO
- **Key responsibilities:**
  - Recruiting, onboarding, offboarding.
  - Performance, compensation, development.
  - Policy, wellbeing, and culture.
  - Steward the [Code of Conduct](code-of-conduct.md) and confidential reporting channel.
- **KPIs:** Time-to-fill `[target]`; retention `[target]`; onboarding completion (target: 100%); engagement score `[target]`.

## 3. RACI matrix

**Legend:** **R** = Responsible (does the work) · **A** = Accountable (owns the outcome; one per row) · **C** = Consulted · **I** = Informed.

Roles are abbreviated: CEO, MER (Merchandising/Buyer), GEM (Gemologist), PROD (Master Jeweler/Setter), QC (QC Lead), SALES (Head of Sales & CX), CX (CX Specialist), MKT (Marketing), OPS (Operations/Fulfillment), FIN (Finance & Compliance), HR (People).

### 3.4 Process: Sourcing a stone

| Step | CEO | MER | GEM | PROD | QC | SALES | OPS | FIN |
|---|---|---|---|---|---|---|---|---|
| Identify assortment need | I | **A/R** | C | I | | C | I | I |
| Solicit & select supplier | I | **A/R** | C | | | | | C |
| Supplier due diligence (KP, OECD, RJC) | I | C | | | | | | **A/R** |
| Verify stone vs. GIA/IGI report | | C | **A/R** | | C | | | I |
| Approve budget & payment | C | C | | | | | | **A/R** |
| Intake into secure inventory | | I | I | | | | **A/R** | I |

### 3.6 Process: Handling a return

| Step | CEO | GEM | PROD | QC | SALES | CX | OPS | FIN |
|---|---|---|---|---|---|---|---|---|
| Authorize return (RMA) | | | | | **A** | R | I | I |
| Insured inbound receipt | | | | | | I | **A/R** | |

> Separation of duties: the role that **authorizes** the refund (SALES/CX) is not the role that **issues** it (FIN). See [Code of Conduct](code-of-conduct.md).

| KYC / beneficial-ownership checks | I | C | | | | **A/R** | |
| Sourcing due diligence (KP, OECD, RJC) | I | C | C | | | **A/R** | |
