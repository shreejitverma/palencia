# Palencia Diamonds — Organizational Documentation

> **Certified diamonds. Handcrafted jewelry. Honest prices.**

This repository is the operating handbook for Palencia Diamonds — the single source of truth for how we run the company, serve our customers, and hold ourselves to the highest standard in fine jewelry.

🌐 [www.palenciadiamonds.com](https://www.palenciadiamonds.com)

## How to use this handbook

- **New to the company?** Start with the [Company Overview](docs/00-company/company-overview.md) and [Mission, Vision & Values](docs/00-company/mission-vision-values.md).
- **Doing a specific job?** Jump to the relevant section below.
- **Editing the docs?** Read the [Documentation Standards](docs/CONTRIBUTING.md) first.

Anything in `[brackets]` marked `TODO:` is a placeholder awaiting company-specific detail.
